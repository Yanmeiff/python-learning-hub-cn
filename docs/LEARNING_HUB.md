# Python Learning Hub V1

本分支在 PyQuest 现有题库和 Pyodide 在线运行环境上增加个人学习数据功能。

## 新增功能

- 作答历史：每次运行都会记录题目、结果、时间、代码、输出和运行错误。
- 错题本：最近一次作答仍未通过的题目自动列入待解决错题。
- 间隔复习：错题首次失败后安排次日复习；连续答对后按 1、3、7、14、30 天递增复习间隔。
- 学习热力图：按天统计提交次数、通过次数和未通过次数。
- 知识掌握度：按题目最近一次作答和难度权重估算六个知识领域的正确率，同时显示练习覆盖率。
- 数据备份：支持导出和导入 JSON，包含学习记录、旧版完成进度和每题保存的代码。

## 数据与隐私

所有学习记录保存在当前浏览器的 localStorage 中，不会自动上传到服务器。清除浏览器站点数据前请先导出备份。不同浏览器、设备或网站域名之间不会自动同步。

旧版 PyQuest 已完成进度和每题代码继续使用原有 localStorage 键。历史上没有保存的错误提交无法追溯，因此错题统计从新版开始记录。

## 掌握度说明

掌握度是学习辅助指标，不是考试成绩或对真实能力的绝对判断。系统按每道题最近一次结果计分，并对中高难度题增加权重；未练习的领域显示“尚未评估”，覆盖率单独展示。

## 开发与测试

开发服务器可通过 npm run serve 启动。
学习数据单元测试命令：node --test tests/*.test.js

GitHub Pages 继续使用仓库的 docs/ 目录发布。
